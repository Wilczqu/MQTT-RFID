# MQTT-RFID
Python written API to connect to a Mosquitto MQTT broker endpoint &amp; subscribe to topics specified by publisher devices to obtain data &amp; extract them into excel

You need to install and configure Mosquitto broker which will be receiving information from your publishing devices. you can download one here https://mosquitto.org/

And its documentation can be found here [https://mosquitto.org/api/files/mosquitto-h.html](https://mosquitto.org/man/mqtt-7.html)
